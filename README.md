# PyQt6 PDF Reader

Desktop PDF reader with a top menu and toolbar, a left control sidebar, and multiple PDFs in closable tabs. The sidebar includes zoom, page number, previous/next page, and fit width/fit height controls.

## Run

Activate the included environment and run `python pdf.py`, or install dependencies with `python -m pip install -r requirements.txt`. You can pass PDF paths as command-line arguments to open them at startup.
